# Lucide Icon Subset

Source: https://github.com/lucide-icons/lucide
Revision: 7faf87628a1ad6175975bc595344337ce14a7db4
License: see LICENSE in this directory (upstream license retained in full).

SVG files are vendored without shape modifications. Runtime rendering substitutes
currentColor and provides normal, active, selected and disabled palettes at 1x/2x/3x.
Only the icons used by the desktop workbench are included; no network is needed.
