- 修改记录必须追加式维护。新增内容应插入为新的日期条目，或在尚未提交的最新条目中补充，不允许覆盖、删除、合并或重写已有历史条目。
- 每条记录至少包含变更摘要、兼容性影响、验证命令或未验证原因。
- 修改记录应与代码提交保持一致；如果一次提交包含多个主题，记录中应拆分为清晰的小节。
- 纯格式化、注释微调或不影响行为的内部整理可以不新增记录，但如果同时更新技术文档，应在对应记录中说明。
