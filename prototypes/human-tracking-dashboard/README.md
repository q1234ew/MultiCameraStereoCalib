# 人体识别与追踪 Dashboard 交互原型

> 已整合进现有 Orin 统一预览：运行 `python -m scripts.jetson.preview --listen 127.0.0.1 --port 8791`，访问 `http://127.0.0.1:8791/#human`。正式界面源文件位于 `scripts/jetson/web/`。本目录保留为早期独立设计参考。

设计预览，不连接相机、Orin 或生产后端。直接打开 `index.html`，或从仓库根目录运行：

```bash
python3 -m http.server 8792 --bind 127.0.0.1 --directory prototypes/human-tracking-dashboard
```

独立参考预览地址：http://127.0.0.1:8792 。该地址只在当前电脑可访问。

## 设计取舍

- 延续现有 Orin 预览的深色蓝系，以空间总览为主，左侧三路相机、右侧人员详情、下方轨迹与关联动态。
- 使用同色全局匿名 ID 联动画面、场景和人员列表。本机 ID 与统一 ID 分别展示，避免把相机间相同编号误当作同一个人。
- 静态场景承载动态人员位置，位置参考点为脚部地面投影。此处的 SVG 是三维示意投影，可切换立体与俯视，并非真实重建场景或交互式三维渲染器。
- 单路观察保留独立 ID；详情显示位置、时间/轨迹、外观等关联证据。演示评分不表示校准概率，也不表示身份识别结果。
- “演示场景”明确标记所有模拟画面、位置、人数、运行指标；“接入记录 · 待刷新”清除模拟数据，并显示已知能力边界。原型不实时查询设备。
- 接入记录只说明 YOLO26n-pose CUDA FP16 静图已验证；未宣称视频追踪、跨相机关联已实测。跨机外参、源帧采集时间与地面坐标系仍需完成核验。
- 手机布局优先场景，后续提供三路缩略图与详情；人员表格允许在表内横向滚动。

## 后续接入边界

真实接入时需由服务提供设备连接状态、源帧时间、每路会话与本机轨迹、经验证的世界坐标、全局匿名 ID 和关联证据。不能以当前请求时间替代采集时间，不能把失效外参下的三维坐标当作已验证结果。JSON 协议输出与模拟展示分别处理，本原型不修改既有输出协议。
